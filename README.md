Abstract
This report presents an object-detection approach for identifying pneumonia-related lung opacity regions in chest X-ray images using the RSNA Pneumonia Detection Challenge dataset. The study compares three configurations: a randomly initialized Faster R-CNN detector, a pretrained Faster R-CNN baseline with a ResNet-50-FPN backbone, and an enhanced DINOv2 semantic-fusion model that combines local region-level detector features with global image-level representations. The implementation emphasizes patient-level data handling, DICOM preprocessing, controlled train-validation-test splitting, and consistent training conditions across experiments. The results show that pretrained detection significantly improves performance over random initialization, while DINOv2 semantic fusion provides comparable primary detection performance with modest improvements in secondary metrics and training stability. The report concludes that transfer learning is highly beneficial for limited medical-imaging experiments, while self-supervised semantic fusion requires more domain-specific adaptation to deliver stronger gains in chest X-ray object detection.
1. Introduction and Objective
Pneumonia-related opacity detection is a clinically relevant computer-vision problem because the visual evidence in chest X-ray images can be subtle, localized, and difficult to identify consistently. The objective of this project is to design and evaluate a practical object-detection pipeline that can localize suspected opacity regions using bounding boxes. Rather than treating the task only as model training, the work is framed as an end-to-end system design problem involving DICOM image handling, label conversion, patient-level grouping, controlled experimentation, and comparative model evaluation. The study is organized into two main specifications: SPEC-1 establishes a strong pretrained Faster R-CNN baseline, while SPEC-2 extends the baseline with DINOv2-based semantic fusion to assess whether global self-supervised visual representations can improve local detection decisions.
2. Dataset and Preprocessing
The experiments use the RSNA Pneumonia Detection Challenge dataset from Kaggle. The dataset consists of chest X-ray images stored in DICOM format, which requires medical-image-specific reading and intensity normalization instead of standard RGB image loading. The full training set contains 26,684 images and 30,227 labeled bounding-box rows. For the scope of this assignment, a stratified 12,000-patient subset was used to balance experimental feasibility with meaningful evaluation. The subset was split at the patient level using a 70/15/15 train-validation-test strategy with seed 42, resulting in 8,400 training images, 1,799 validation images, and 1,801 test images.
The annotation file provides bounding boxes in the RSNA format of x, y, width, and height. During preprocessing, these labels were converted into the Torchvision object-detection format of x_min, y_min, x_max, and y_max. Images with multiple opacity regions were retained as single samples with multiple bounding boxes, preserving the relationship between one patient image and all associated findings. This design avoids duplicate image treatment and produces a cleaner training signal for object detection.
